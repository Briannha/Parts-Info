FORD PAGE PACKAGE
=================

Unzip this package into the ROOT of Briannha/Parts-Info.

It contains:
- ford.html
- assets/ford.css
- assets/ford-underwater-background.png
- alternate generated underwater frames in assets/

The CSS is already changed to use the local underwater image rather than the old external Google thumbnail URL.

Existing files such as assets/style.css, assets/site.js and the music folder are NOT included and should remain in place.

Note:
The included PNGs are generated visual frames. A true animated GIF/WebP has not been assembled in this package yet; the alternate frames are included so they can be converted into a looping animation later without regenerating the scene.
